# Symbolic Control for Autonomous Mobile Robots

This project explores **symbolic control techniques** for autonomous mobile robots, focusing on formal methods to ensure correct and safe robot behavior in various tasks.

---

## 🧩 Project Overview

The goal of this project is to design controllers for autonomous mobile robots using **symbolic methods**. Symbolic control allows us to model robot behavior with **automata** and formally guarantee that certain specifications, such as safety and reachability, are met.

In this project, we implemented and analyzed the following scenarios:

1. **Reachability** – Ensuring the robot can reach a designated target or goal region.
2. **Safety** – Guaranteeing the robot avoids unsafe areas or obstacles at all times.
3. **Reachability + Safety** – Combining both objectives: the robot reaches its goal **while remaining safe**.
4. **Robot Delivery** – A practical example where the robot delivers an item from a start location to a target, respecting safety constraints.

---
## 🖥 Notebook Highlights

The notebook demonstrates:

- **Automata Modeling** – Representing robot states, actions, and transitions.
- **Simulation of Motion** – Robot trajectories in 2D and 3D under different control strategies.
- **Formal Analysis** – Checking reachability and safety conditions.
- **Visualization** – 2D and 3D plots showing robot paths, safe zones, and goal regions.
